# API

`GET /health`; payment/refund/settlement collection endpoints; `POST /api/v1/reconciliation/run`; cases at `/api/v1/reconciliation/cases`; RCA at `/api/v1/rca/{case_id}`; dashboard summary at `/api/v1/dashboard/summary`; Razorpay webhook at `/api/v1/webhooks/razorpay`. Interactive OpenAPI documentation is `/docs`.
